## 5. 남은 과제 (기준표 10절 31~34번)

1. **표본 수의 대리 지표** — 설치 수(예: VS Code 마켓 7,495만)와 리뷰 수(404건)가 다른 정보인데 지금은 리뷰 수만 센다.
2. **게이트 경계(70·60)와 100점 상한** — 90종이 100.0에 몰려 '누가 더 검증됐는가'를 더 보여주지 못한다.
3. **리뷰 수 미공개 도구** — 마켓이 리뷰 수를 숨기면 stars 대리값만 남는다.
4. **티어 오버라이드** — `axis_overrides.user_rating`(Vampire Survivors 모바일 74)에는 아직 적용하지 않았다.
